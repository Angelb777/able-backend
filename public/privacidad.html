2. Qué datos personales podemos tratar

Los datos tratados dependen de las funcionalidades que utilice cada usuario.

2.1. Datos de cuenta y perfil

Para crear y gestionar una cuenta podemos tratar:

  • Dirección de correo electrónico.
  • Nickname o nombre de usuario.
  • Nombre y apellidos, cuando sean facilitados.
  • Foto de perfil, avatar o skin.
  • Rol o tipo de usuario.
  • Identificadores internos de la cuenta.
  • Proveedor utilizado para iniciar sesión, como Google.
  • Información necesaria para verificar y proteger la cuenta.

2.2. Datos de ubicación

Determinadas funcionalidades de Able73 requieren conocer la ubicación del dispositivo.

Cuando el usuario haya concedido los permisos correspondientes, Able73 puede tratar:

  • Ubicación geográfica del dispositivo.
  • Coordenadas necesarias para las funcionalidades de movilidad.
  • Posición necesaria para determinadas funciones multijugador.
  • Origen y destino cuando el usuario solicita rutas.
  • Información necesaria para localizar servicios, vehículos, comercios u otros elementos cercanos.

En determinadas funcionalidades de juego, la posición del usuario puede utilizarse para mostrar su presencia a otros usuarios cercanos.

La ubicación precisa no se utiliza para mostrar públicamente información como el correo electrónico o la identidad civil del usuario.

2.3. Datos de actividad y movimiento

Able73 puede tratar información procedente del dispositivo para detectar determinadas actividades o desplazamientos, incluyendo:

  • Número de pasos.
  • Información relacionada con movimiento y actividad física.
  • Datos necesarios para detectar desplazamientos a pie, bicicleta u otros medios habilitados.
  • Velocidad u otros parámetros necesarios para validar determinada actividad.

Esta información puede utilizarse para calcular actividad, recompensas y Stepcoins.

2.4. Datos relacionados con la utilización de Able73

Podemos tratar información relacionada con:

  • Stepcoins obtenidos, utilizados o adquiridos.
  • Rachas y recompensas.
  • Rankings.
  • Experiencia y progreso.
  • Cartas, skins y otros elementos virtuales.
  • Duelos, combates y otras mecánicas de juego.
  • Clanes y otras funcionalidades sociales.
  • Promociones y recompensas utilizadas.
  • Actividad necesaria para prevenir fraude o manipulación.

2.5. Datos técnicos y del dispositivo

Para el funcionamiento, seguridad y diagnóstico del servicio podemos tratar:

  • Tipo de dispositivo.
  • Sistema operativo.
  • Versión de la aplicación.
  • Identificadores técnicos necesarios para el funcionamiento del servicio.
  • Información de sesión.
  • Registros técnicos y de seguridad.
  • Información necesaria para detectar errores, fraude o accesos no autorizados.

Determinadas funciones relacionadas con dispositivos, vehículos o candados pueden utilizar además identificadores técnicos o información Bluetooth necesaria para establecer la correspondiente conexión.

2.6. Datos de compras y operaciones

Cuando Able73 habilite funcionalidades de pago o compras, podremos tratar:

  • Producto o servicio adquirido.
  • Importe y moneda.
  • Fecha y estado de la operación.
  • Identificador de la transacción.
  • Datos de facturación cuando sean necesarios.
  • Nombre, teléfono, NIF o dirección cuando sean necesarios para gestionar una compra, envío o factura.

Cuando los pagos sean gestionados por una pasarela externa, los datos completos de la tarjeta u otro medio de pago serán tratados directamente por el proveedor de pagos correspondiente y no por Able73, salvo la información necesaria para identificar y gestionar la operación.

2.7. Datos de comercios y otros perfiles profesionales

Determinados perfiles profesionales o funcionalidades específicas pueden requerir información adicional, como:

  • Nombre o razón social.
  • Datos de contacto profesional.
  • Dirección del establecimiento.
  • Información comercial.
  • Documentación necesaria para prestar determinados servicios.

2.8. Comunicaciones con Able73

Cuando el usuario contacte con Able73 podemos tratar:

  • Nombre o nickname.
  • Correo electrónico.
  • Contenido de la consulta.
  • Información necesaria para resolver una incidencia.

3. Para qué utilizamos los datos y cuál es la base jurídica

3.1. Crear y gestionar la cuenta

Utilizamos los datos para registrar usuarios, autenticar accesos, gestionar sesiones y mantener el perfil.

Base jurídica: ejecución de la relación contractual con el usuario y aplicación de medidas solicitadas antes de crear la cuenta.

3.2. Prestar las funcionalidades de movilidad y actividad

Utilizamos los datos necesarios para registrar determinadas actividades, desplazamientos, calcular recompensas, mostrar servicios cercanos y prestar las funciones de movilidad solicitadas.

Base jurídica: ejecución del servicio solicitado por el usuario y, cuando resulte legalmente necesario para una funcionalidad opcional, el consentimiento del usuario.

Los permisos concedidos a través del sistema operativo permiten al usuario controlar técnicamente el acceso de Able73 a ubicación, actividad u otros sensores del dispositivo.

3.3. Calcular Stepcoins y recompensas

Los datos de actividad pueden utilizarse para calcular los Stepcoins, recompensas, rachas y otros elementos asociados al funcionamiento de Able73.

Base jurídica: ejecución de la relación contractual y prestación del servicio solicitado.

3.4. Funciones de juego y multijugador

Los datos pueden utilizarse para permitir rankings, duelos, combates, clanes, presencia de otros usuarios y demás funcionalidades sociales o multijugador.

Dependiendo de la función, otros usuarios pueden visualizar información como nickname, avatar o skin, rango, estadísticas, clan y presencia o posición necesaria para la mecánica de juego.

Base jurídica: ejecución del servicio solicitado por el usuario.

3.5. Proporcionar mapas, rutas y servicios relacionados con movilidad

Podemos utilizar ubicación, origen, destino u otros datos necesarios cuando el usuario solicita rutas, mapas, lugares cercanos, información meteorológica o servicios relacionados con movilidad.

Base jurídica: ejecución de la funcionalidad solicitada.

3.6. Gestionar compras y pagos

Cuando las funcionalidades de pago estén habilitadas, utilizaremos los datos necesarios para gestionar compras, operaciones, facturación, incidencias y devoluciones.

Base jurídica: ejecución del contrato y cumplimiento de obligaciones legales, fiscales, contables y de consumo.

3.7. Seguridad y prevención del fraude

Able73 puede analizar información técnica, actividad, operaciones y otros datos necesarios para:

  • Proteger las cuentas de usuario.
  • Detectar accesos no autorizados.
  • Evitar manipulación de ubicación o actividad.
  • Detectar obtención fraudulenta de Stepcoins o recompensas.
  • Investigar abusos o vulnerabilidades.
  • Proteger la seguridad y estabilidad de la plataforma.

Base jurídica: interés legítimo de Able73 en mantener la seguridad de la plataforma, prevenir el fraude y proteger a sus usuarios.

3.8. Atención al usuario

Utilizamos la información facilitada para responder consultas, gestionar incidencias y prestar asistencia.

Base jurídica: ejecución de la relación con el usuario e interés legítimo en atender correctamente las solicitudes recibidas.

3.9. Cumplimiento de obligaciones legales

Able73 podrá tratar o conservar determinados datos cuando resulte necesario para cumplir obligaciones legales, fiscales, contables, administrativas o atender requerimientos legítimos de autoridades.

Base jurídica: cumplimiento de una obligación legal.

3.10. Comunicaciones comerciales

Able73 no enviará comunicaciones comerciales que requieran consentimiento sin haber obtenido previamente dicho consentimiento.

Cuando se habilite esta posibilidad, el usuario podrá retirar su consentimiento en cualquier momento.

3.11. Publicidad

Able73 puede incorporar espacios publicitarios mediante proveedores externos.

Cuando la utilización de identificadores, cookies, almacenamiento del dispositivo o datos para publicidad requiera consentimiento conforme a la normativa aplicable, dichas funcionalidades deberán utilizarse únicamente después de obtener el consentimiento correspondiente.

  • Directamente del usuario.

  • De proveedores de autenticación, como Google, cuando el usuario decide iniciar sesión mediante dichos servicios.
  • De proveedores necesarios para prestar una funcionalidad solicitada.
  • De operaciones y actividad realizadas dentro de Able73.
  • De fuentes públicas relacionadas con servicios de movilidad cuando corresponda.

Able73 no vende los datos personales de sus usuarios.

Para prestar determinados servicios, algunos datos pueden ser comunicados o resultar accesibles para proveedores tecnológicos que actúan por cuenta de Able73 o que prestan directamente determinadas funcionalidades.

Entre ellos pueden encontrarse:

  • Proveedores de alojamiento, infraestructura y servicios informáticos.
  • Google Firebase para autenticación y servicios técnicos asociados.
  • Google Sign-In cuando el usuario decide utilizar este método de acceso.
  • Google Maps, Places, Directions u otros servicios relacionados con mapas, lugares y rutas.
  • Proveedores de pago cuando se realicen operaciones económicas.
  • Proveedores de información meteorológica.
  • Proveedores u operadores de movilidad cuando sean necesarios para prestar una funcionalidad solicitada.
  • Proveedores de publicidad cuando dicha funcionalidad esté habilitada y se cumplan los requisitos de consentimiento aplicables.
  • Otros proveedores técnicos necesarios para mantener y proteger Able73.

Able73 procurará comunicar únicamente los datos necesarios para proporcionar cada servicio.

También podrán comunicarse datos a administraciones públicas, fuerzas y cuerpos de seguridad, juzgados, tribunales u otras autoridades cuando exista una obligación legal o un requerimiento válido.

Algunos proveedores tecnológicos utilizados por Able73 pertenecen a grupos empresariales internacionales o pueden tratar información desde países situados fuera del Espacio Económico Europeo.

Cuando se produzca una transferencia internacional de datos personales, Able73 utilizará proveedores que dispongan de un mecanismo válido conforme al RGPD.

Estos mecanismos pueden incluir:

  • Decisiones de adecuación adoptadas por la Comisión Europea.
  • El Marco de Privacidad de Datos UE-EE. UU., cuando resulte aplicable al proveedor correspondiente.
  • Cláusulas Contractuales Tipo aprobadas por la Comisión Europea.
  • Otras garantías reconocidas por la normativa de protección de datos.

8. Durante cuánto tiempo conservamos los datos

Able73 conservará los datos personales únicamente durante el tiempo necesario para cumplir la finalidad para la que fueron obtenidos.

Con carácter general:

  • Los datos de cuenta y perfil se conservarán mientras la cuenta permanezca activa.
  • Los datos necesarios para proporcionar funciones en tiempo real se tratarán durante el tiempo necesario para prestar dichas funcionalidades.
  • Los registros de actividad, recompensas, Stepcoins y operaciones podrán conservarse mientras sean necesarios para gestionar la cuenta, mantener el funcionamiento del servicio y prevenir fraude.
  • Los datos relacionados con compras, facturación y operaciones económicas se conservarán durante los plazos exigidos por la normativa fiscal, mercantil y demás normativa aplicable.
  • Los registros de seguridad podrán conservarse durante el tiempo razonablemente necesario para detectar, investigar y prevenir incidentes.

Cuando el usuario solicite la eliminación de su cuenta, sus datos serán eliminados o anonimizados cuando resulte posible.

No obstante, determinados datos podrán permanecer bloqueados durante los plazos legalmente aplicables cuando sean necesarios para atender obligaciones legales o posibles responsabilidades.

Able73 procurará no conservar información de ubicación precisa durante más tiempo del necesario para las finalidades que justificaron su tratamiento.

9. Datos obligatorios y datos opcionales

Algunos datos son necesarios para crear una cuenta o prestar determinadas funcionalidades.

Cuando un dato sea obligatorio, la imposibilidad de proporcionarlo puede impedir la creación de la cuenta o el uso de la funcionalidad correspondiente.

Los permisos del dispositivo, como ubicación o reconocimiento de actividad, pueden modificarse desde la configuración del propio dispositivo.

Si el usuario desactiva un permiso, las funciones que dependan de dicho permiso pueden dejar de estar disponibles o funcionar de manera limitada.

10. Decisiones automatizadas

Able73 utiliza procesos automáticos para determinadas funciones internas, como calcular actividad, Stepcoins, recompensas, rankings o mecánicas relacionadas con el juego.

En la actualidad, estos procesos no tienen como finalidad adoptar decisiones exclusivamente automatizadas que produzcan efectos jurídicos sobre el usuario o que le afecten significativamente de forma similar en los términos previstos por el artículo 22 del RGPD.

Los usuarios pueden ejercer los derechos reconocidos por la normativa de protección de datos.

En particular, pueden solicitar:

  • Acceso: conocer qué datos personales tratamos.

  • Supresión: solicitar la eliminación de sus datos cuando corresponda.
  • Limitación: solicitar que se limite el tratamiento en determinados supuestos.
  • Oposición: oponerse a determinados tratamientos cuando legalmente proceda.
  • Portabilidad: recibir determinados datos en un formato estructurado y transmitirlos a otro responsable cuando resulte aplicable.
  • Retirar el consentimiento: cuando un tratamiento se base en consentimiento, este puede retirarse en cualquier momento sin afectar a la licitud del tratamiento realizado anteriormente.

El usuario también tiene derecho a presentar una reclamación ante la Agencia Española de Protección de Datos (AEPD) si considera que el tratamiento de sus datos personales no se ajusta a la normativa.

12. Menores de edad

Able73 no está dirigida a menores de 14 años que actúen por sí mismos cuando el tratamiento de sus datos personales dependa de su consentimiento.

En España, cuando el tratamiento de los datos de un menor de 14 años esté basado en consentimiento, este deberá ser otorgado o autorizado por sus padres, tutores o representantes legales conforme a la normativa aplicable.

Determinadas operaciones, compras o servicios realizados por menores pueden requerir además la autorización de sus representantes legales.

Si Able73 tiene conocimiento de que se han tratado indebidamente datos de un menor, adoptará las medidas razonables necesarias para corregir la situación.
